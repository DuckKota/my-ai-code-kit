# My OMP Command Cheatsheet

Personal reference for my Oh My Pi workflow. Kit commands land in both OMP and
OpenCode; OMP-native commands are built into Oh My Pi.

## Commands

| Command | What it does |
| --- | --- |
| `/commit-message` | Generate a Conventional Commit message from your staged changes |
| `/grill-me` | Grill you relentlessly to sharpen a plan, decision, or idea |
| `/fix` | Diagnose and fix a bug or performance regression |

### OpenSpec

| Command | What it does |
| --- | --- |
| `/opsx-propose` | Propose a new change with design, specs, and tasks |
| `/opsx-apply` | Implement tasks from an OpenSpec change |
| `/opsx-archive` | Archive a completed OpenSpec change |

### Ponytail

| Command | What it does |
| --- | --- |
| `/ponytail` | Set intensity: lite, full, ultra, off (no arg reports current) |
| `/ponytail-review` | Find over-engineering in the current diff |
| `/ponytail-audit` | Scan the whole repo for bloat |

## OMP-native

| Command | What it does |
| --- | --- |
| `/review` | Run a focused, read-only review of a branch, working copy, commit, or GitHub pull request |
| `/advisor` | Run a background AI agent that oversees the primary agent |
| `/btw` | 	Asks an ephemeral side question with current context; the exchange is not added to the persisted conversation |
